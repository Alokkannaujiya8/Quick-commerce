# AI Audit & Engineering Reports Directory

This directory stores formal audit reports, architectural verification reviews, and post-task completion summaries produced by AI coding agents.

---

## Report File Naming Convention

Report files should be named:
```text
YYYY-MM-DD-<short-topic-name>-report.md
```
Example: `2026-10-02-backend-documentation-audit-report.md`
