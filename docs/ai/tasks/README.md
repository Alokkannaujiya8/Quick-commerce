# AI Implementation Tasks Directory

This directory stores implementation task specifications, plans, and tracking documents for major engineering efforts executed by AI coding agents.

---

## Task File Naming Convention

Task files should be named:
```text
TASK-<YYYYMMDD>-<short-description>.md
```
Example: `TASK-20261002-backend-documentation-integration.md`

---

## Directory Contents

* **[`TASK-TEMPLATE.md`](TASK-TEMPLATE.md)**: Standard template to use when planning and documenting a new engineering task.
